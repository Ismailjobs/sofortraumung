# Soforträumung.at

Professionelle Räumungs-Landingpage – Next.js (App Router), TypeScript, Tailwind CSS, lucide-react.

## Start

```bash
npm install
npm run dev
```

Öffne [http://localhost:3000](http://localhost:3000).
